# ToDo List — базовий рівень (тільки frontend)

Список справ у стилі "паперового чека". Все в одному файлі `index.html`
(HTML + CSS + JS). Завдання зберігаються у **localStorage браузера**.

## Як запустити

Просто відкрити `index.html` у будь-якому браузері — сервер не потрібен.

## Що вміє

- Додавати завдання через поле вводу або клавішу Enter.
- Відмічати завдання як виконане (клік по квадратику-штампу) — текст
  перекреслюється, штамп "проштамповується".
- Видаляти окреме завдання (кнопка "видалити") з анімацією "відриву".
- Очищати весь список одразу (кнопка під штрих-кодом).
- Лічильник пунктів і лічильник виконаних завдань оновлюються живо.
- Дані не зникають після перезавантаження сторінки — все читається й
  пишеться у `localStorage` під ключем `todo-receipt-tasks`.

## Структура даних у localStorage

```json
[
  { "id": "abc123", "text": "Купити молоко", "done": false }
]
```
